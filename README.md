# نظام إدارة الطلبات — لازم للخدمات الطبية

الإصدار: v2026.11.15

## طريقتان للنشر (اختر واحدة فقط)

1. **ملف واحد (الأسهل):** ارفع `index.html` المستقل (المرسل منفصلاً، حجمه ~6MB) وحده — فيه كل شيء حتى الفيديوهات.
2. **هذا المجلد:** ارفع كل الملفات كما هي في نفس المكان (كلها بجانب `index.html`، بدون مجلدات):
   `index.html, style.css, app.js, logo.js, images.js, manifest.json, sw.js, icon-*.png, login.mp4, form.mp4, dashboard.mp4`
   (لو كانت الفيديوهات داخل مجلد `videos` تعمل أيضاً.)

بعد الرفع: انتظر دقيقة حتى يتحدث GitHub Pages، ثم حدّث الصفحة بـ Ctrl+Shift+R وتأكد من رقم الإصدار أسفل يسار الصفحة.

## التشغيل محلياً
افتح المجلد في VS Code وشغّل `index.html` بإضافة Live Server.

## أهم المزايا
- أربع خدمات: عقود النقل، تغطية الفعاليات، تغطية المشاريع، الدورات التدريبية
- ضمن الدورات: جهاز AED (أجهزة طبية) وحقائب الإسعافات الأولية (مستلزمات طبية)
- كود المشروع LZM تلقائي حسب معيار الترميز
- حفظ فوري محلي + مزامنة بالخلفية مع Firebase Firestore (يعمل بدون اتصال)
- تعديل وحذف فوري، تاريخ تسليم التسعيرة ومتابعة الاستحقاق
- نسخ/مشاركة نص الطلب (بدون إيموجي)، تصدير Excel بتنسيق ملف الـ CRM
- وضع ليلي/نهاري، يعمل على الجوال، قابل للتثبيت كتطبيق (PWA)
